Description

Coverage of primary ONT read alignments from the cell types named in each track.

These tracks originate from the combined diploid KOLF2.1Jv1.1 hub and are exposed separately on the primary and alternate GenArk assemblies using UCSC's existing chromosome aliases. Only nuclear chromosomes are enabled; the source mitochondrial sequence differs from the NCBI primary assembly.

Methods

The source hub supplies bigWig coverage summaries of ONT alignments. Here, primary describes the read alignment, not the assembly haplotype.

This configuration migration reuses the original data files without recomputing annotations.

Credits

Data supplied by the T2T KOLF genome browser contributors and hosted in the human-pangenomics public data collection. The KOLF assemblies were submitted to NCBI by NHGRI.
