KOLF2.1Jv1.1 alternate assembly

Description

The alternate pseudohaplotype of the diploid KOLF2.1J induced pluripotent stem cell (iPSC) genome, assembly name KOLF2.1Jv1.1.alt.

Scientific name: Homo sapiens (taxonomy ID 9606)
Assembly submitter: NHGRI
NCBI release date: 17 June 2026
Assembly level: Chromosome
Assembly accession: GCA_058280805.1
BioSample: SAMN60427383
Paired assembly: GCA_058280895.1

Annotation coordinates

These tracks reuse the combined diploid data from the original KOLF2.1Jv1.1 hub. UCSC's GenArk aliases map the original chromosome names to this assembly's GenBank sequence accessions. The 22 nuclear chromosome lengths match the original hub's chromosome sizes.

Contributed tracks are restricted to nuclear chromosomes. The original hub's mitochondrial sequence is 21,116 bases, whereas the NCBI primary assembly's mitochondrial sequence is 16,581 bases; those coordinates must not be treated as interchangeable. The alternate assembly contains only autosomes.

Methods

NCBI reports PacBio, Oxford Nanopore and Hi-C sequencing and assembly with Verkko v1.4–v2.0. Track-specific documentation describes the available source annotations. Separate configuration files are maintained for each haplotype.

Credits

Assembly submitted by NHGRI. Annotation files are supplied through the T2T KOLF browser data collection.
