T2T Consortium Contributed Tracks

Description

This hub contains annotation tracks contributed by the Telomere-to-Telomere (T2T) Consortium for genome assemblies produced or curated by the consortium. Tracks include assembly validation metrics, repeat annotations, gene models, transcription and epigenetic evidence, regulatory element predictions, comparisons to GRCh38/GRCh37, human variation resources lifted to T2T coordinates, and comparative genomics alignments (chain and HAL/Cactus alignments) to other T2T primate assemblies.

This release covers the T2T-CHM13v2.0 assembly (UCSC database hs1, NCBI accession GCA_009914755.4), the HG002v1.1 maternal and paternal haplotypes (NCBI accessions GCA_018852615.3 and GCA_018852605.3, respectively), and the v2.0 primary assemblies for gorilla, bonobo, chimpanzee, Sumatran orangutan, Bornean orangutan, and siamang. Each assembly has an independent track configuration in the per-assembly layout described at Contributing Tracks to the UCSC Genome Browser.

The hub also includes the separate maternal and paternal component assemblies for gorilla and bonobo. Component assemblies expose only tracks whose source files contain the corresponding haplotype chromosome namespace; annotations generated specifically for the primary pseudohaplotype are not included.

The alternate pseudohaplotype assemblies for chimpanzee, Sumatran orangutan, Bornean orangutan, and siamang are also included. These assemblies expose only tracks whose source files contain the alternate (hap2) autosomal chromosome namespace; primary-only annotations and sex-chromosome subtracks are not included.

Methods

Tracks were generated by members of the T2T Consortium and collaborating labs using a variety of methods, including long-read sequencing alignments, repeat annotation pipelines (RepeatMasker, segmental duplication detection), gene projection/liftoff from GRCh38/RefSeq, epigenetic assays (ONT/PacBio methylation calling), chromatin accessibility (FIRE), and whole-genome alignments produced with wfmash and Cactus/HAL. See each track's own description page (linked from the track configuration page) for method-specific details.
