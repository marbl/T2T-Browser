Description

This track maps locations in the HG002v1.1 genome to their corresponding position on the opposite haplotype of the same chromosome.

To determine correspondence between the haplotypes, the set of all autosomal maternal chromosomes in hg002v1.1 were aligned to the set of all autosomal paternal chromosomes with minimap2, and vice versa. After filtering to include only alignments between strictly homologous regions, chain files were created to lift positions from one of each chromosome's haplotypes to the other. From those chain files, UCSC browser "bigChain" files were created using the UCSC software toolkit.

Display Conventions and Configuration

Chromosome colors are specified in the "Chromosome Color Key" displayed below the browser panel.

Methods

Chain files for lifting coordinates between homologous chromosome pairs in the HG002v1.1 assembly were created using the "nf-LO" pipeline described in Rhie et al., Nature 2023. Briefly, we used nextflow to run nf-LO (Talenti and Prendergast, Genome Biology and Evolution 2021) to align each autosomal HG002v1.1 chromosome to its homologous chromosome on the other haplotype of HG002v1.1 with minimap2. Then, we split the chains at all locations where there were unaligned segments longer than 1kbp or gaps longer than 10kbp. Only alignments between homologous chromosomes were retained (e.g., between chr1_MATERNAL and chr1_PATERNAL, but not between chr1_MATERNAL and chr3_PATERNAL). The package rustybam (https://github.com/mrvollger/rustybam) was used to trim overlapping portions of the chains, resulting in one-to-one alignments, and finally, the package chaintools was used to invert chains to obtain chain files for the reverse direction.
