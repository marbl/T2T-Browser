Description

This track shows the locations of homopolymer runs in the T2T-HG002v1.1 genome.

Display Conventions and Configuration

The BED entries for homopolymers are colored by the forward-strand nucleotide that is repeated:
  •     - A
  •     - T
  •     - G
  •     - C

Methods

The script used to create this track is part of the GQC software package. By default it catalogs all homopolymer runs of length ten or greater in the FASTA reference being analyzed. For this track, it was called with this usage:

mononucs --fasta v1.1.fasta.gz --prefix v1.1.mnr10
