Description

This track displays regions that are considered "suspect" in HG002v1.1.

Display Conventions and Configuration

Unlike the "v1.1 issues" track, which displays GitHub issues in the repository at https://github.com/marbl/HG002-issues, the "v1.1 Suspicious Regions" track also contains regions that were determined to be problematic in the v1.0.1 region and (a) were not able to be corrected in the v1.1 assembly and (b) were not supported by two high-quality assemblies performed with newer data.

This set of regions is also the default set to be excluded when running GQC to benchmark genome assemblies or sequencing reads using the HG002v1.1 genome benchmark.
